# InmoData

InmoData helps Dominican Republic property buyers understand whether a listing price is below, within, or above its local market range.

## MVP scope

Apartments for sale in:

- Naco
- Piantini
- Evaristo Morales
- Bella Vista
- Los Cacicazgos

## Technology

- Django and Python
- SQLite for local development
- PostgreSQL for production
- Python data analysis tools later

## Data principles

InmoData links to original listing sources and does not reuse listing images or descriptions.
